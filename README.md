# Бюджетът

Сайт с данни за държавния бюджет на България от 1989 г. насам. Дефицитът, дългът, инфлацията и неравенството са наредени по години до правителствата, парламентите и изборите.

Сайтът е на адрес <https://vibe-nation.github.io/the-budget/>.

## Какво показва графиката

- **Данни от Евростат:** държавен дефицит/излишък и държавен дълг, в евро и като % от БВП, годишна инфлация (ХИПЦ) и коефициент на Джини.
- **Данни от законите за бюджета:** бюджетите на МВР, на съдебната власт и на органите в нея, както и максималният осигурителен доход.

При клик върху показател се отваря обяснение какво означава той, с източниците към него. Стойностите от законите за бюджета водят до заглавието на закона, броя на „Държавен вестник“, страницата, члена и алинеята.

## Стартиране

```bash
npm install
npm start
```

След това сайтът се отваря на `http://localhost:4200/`.

## Команди

| Команда         | Какво прави                                            |
| --------------- | ------------------------------------------------------ |
| `npm start`     | Пуска сървър за разработка с презареждане при промяна. |
| `npm run build` | Прави продукционна версия в `dist/the-budget/browser`. |
| `npm test`      | Пуска тестовете с Vitest.                              |

Продукционната версия е с базов адрес `/the-budget/`, защото сайтът е в подпапка на GitHub Pages. Затова адресите в приложението трябва да остават относителни.

## Структура

| Път                     | Съдържание                                                                           |
| ----------------------- | ------------------------------------------------------------------------------------ |
| `src/app/charts`        | Графиката по години.                                                                 |
| `src/app/documentation` | Страницата с документация на сайта.                                                  |
| `public/data`           | Данните на графиката: серии, събития, избори, длъжности и бюджетни периоди.          |
| `public/data/metrics`   | Обясненията, по един Markdown файл за показател.                                     |
| `public/data/eurostat`  | Суровите файлове от Евростат, от които идват сериите. Описани са в своя `README.md`. |
| `public/budget`         | Законите за държавния бюджет за 2000–2026 г. в PDF. Описани са в своя `README.md`.   |
| `.claude/skills`        | Уменията за Claude Code, с които се добавят и обновяват показателите.                |

## Добавяне на показател

Показателите се добавят с Claude Code. Отворете го в папката на проекта и опишете какво искате. Подходящото умение се включва само, а можете да го извикате и по име:

- `/eurostat-extract` добавя показател от Евростат на графиката, винаги за всички години.
- `/budget-chart` изважда суми от законите за бюджета и пази източника на всяка стойност.
- `/describe-metric` пише обяснението, което читателят вижда при клик върху показател.
- `/verify-mandates` добавя и проверява мандатите на хората по длъжности в `public/data/roles.json`.

Подробности и примери има на страницата [Документация](https://vibe-nation.github.io/the-budget/#/documentation).
